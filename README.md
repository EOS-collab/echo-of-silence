# Echo of Silence

Выживание в мёртвой Москве.

## Скачать

**[EchoLauncher.exe](https://github.com/EOS-collab/echo-of-silence/releases/latest/download/EchoLauncher.exe)** — 69 МБ, больше ничего качать не нужно.

Запустите, нажмите «Установить» — лаунчер поставит себя, создаст ярлыки и скачает игру сам. Права администратора не нужны. Удаляется как обычная программа, через «Приложения и возможности».

Игра занимает **581 МБ**, нужна Windows 10 или 11 (64-разрядная).

> При первом запуске Windows покажет синее окно «Защита системы Windows». Это не вирус: так система встречает любую программу без платной подписи разработчика. Нажмите «Подробнее» → «Выполнить в любом случае».

## Для тех, кто выпускает обновления

Этот репозиторий — не исходники игры. Здесь живут две вещи, которые нужны игрокам:

| | |
|---|---|
| `docs/index.html` | страница новостей, её же показывает лаунчер в своём окне |
| `docs/version.json` | манифест текущей версии: список файлов с контрольными суммами |

Сами файлы игры лежат в **Releases** — по одному файлу на ассет, чтобы обновление качало только изменившееся, а не всю игру заново.

## Как это работает у игрока

1. Лаунчер читает `docs/version.json` (через GitHub Pages).
2. Сверяет каждый файл на диске по SHA-256.
3. Качает несовпавшие из релиза, проверяет хеши, и только потом подменяет.

Обрыв связи посреди обновления оставляет рабочую игру: пока не скачано и не проверено всё, ни один файл игры не трогается.

## Как выпустить обновление

```powershell
# 1. Собрать игру для раздачи
powershell -File "<проект игры>\Tools\package.ps1" -Release

# 2. Написать, что изменилось, в Tools\release-notes.txt
#    (строка без значка - заголовок, строки с "-" - пункты списка)

# 3. Манифест + плоские копии файлов для релиза
powershell -File "<лаунчер>\Tools\publish.ps1" `
    -Version 0.9.2 -Owner EOS-collab -Repo echo-of-silence

# 4. Залить релиз (нужен токен с правом repo)
$env:GITHUB_TOKEN = "<токен>"
powershell -File "<лаунчер>\Tools\upload_release.ps1" -Version 0.9.2 -Owner EOS-collab -Repo echo-of-silence

# 5. Отправить обновлённый манифест и новости
git add docs; git commit -m "0.9.2"; git push
```

После пятого шага у каждого игрока при следующем запуске лаунчера кнопка «ИГРАТЬ» превращается в «ОБНОВИТЬ», а рядом появляется список изменений.

## Pages

Уже настроены: ветка `main`, папка `/docs`. Страница — `https://eos-collab.github.io/echo-of-silence/`, манифест — `.../version.json`. Этот адрес зашит в лаунчер как значение по умолчанию (`Settings.DefaultManifestSource`), так что скачанный игроком лаунчер знает, куда идти, ещё до первого запуска.

## Чего здесь нет намеренно

**Файлов игры в самом git.** Один из них весит 314 МБ, а git не берёт файлы больше 100 МБ. Для двоичных сборок существуют релизы, для этого они и нужны.

**Подписи кода.** Её нет, и поэтому при первом запуске Windows покажет синее предупреждение SmartScreen. Сертификат стоит 100–400 долларов в год; бесплатного способа убрать это предупреждение не существует.
